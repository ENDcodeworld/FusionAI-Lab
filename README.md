## 🌍 Why Nuclear Fusion?

- 🟢 **零碳排放** — 最清洁的能源方案之一
- 🔋 **几乎无限** — 海水中含有丰富的氘燃料
- ⚡ **高效安全** — 无长寿命放射性废料
- 🌍 **能源自由** — 告别化石燃料依赖
