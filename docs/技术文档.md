## 1. 项目概述

### 1.1 项目背景

FusionAI-Lab 是一个专注于核聚变产业的数据智能平台，旨在：
- 追踪全球核聚变公司和融资动态
- 提供行业数据分析和可视化
- 生成深度行业研究报告
- 加速聚变能源商业化进程

### 1.2 核心价值

| 用户类型 | 核心价值 |
|----------|----------|
| 投资者 | 获取聚变公司融资数据，辅助投资决策 |
| 研究人员 | 追踪行业技术发展和论文动态 |
| 政策制定者 | 了解产业发展趋势，制定支持政策 |
| 公众 | 科普核聚变知识，提高认知 |

### 1.3 功能模块

```
FusionAI-Lab
├── 公司数据库 (Companies Database)
│   ├── 公司信息管理
│   ├── 技术路线分类
│   └── 地理分布展示
│
├── 融资追踪 (Funding Tracker)
│   ├── 融资事件记录
│   ├── 统计数据可视化
│   └── 趋势分析
│
├── 数据可视化 (Data Visualization)
│   ├── 融资趋势图
│   ├── 技术路线分布
│   └── 地理分布地图
│
├── 报告系统 (Report System)
│   ├── 年度行业概览
│   ├── 季度报告
│   └── 公司深度分析
│
└── 论文数据库 (Paper Database)
    ├── 学术论文收录
    └── 引用统计
```

## 2. 系统架构

### 2.1 技术栈

#### 后端
- **框架:** FastAPI (Python 3.11+)
- **数据库:** PostgreSQL 15 + SQLAlchemy (异步)
- **缓存:** Redis 7
- **认证:** JWT
- **文档:** OpenAPI/Swagger

#### 前端
- **框架:** React 18 + TypeScript
- **UI 组件:** Ant Design 5
- **可视化:** ECharts + Three.js
- **状态管理:** Zustand
- **构建工具:** Vite

#### 基础设施
- **容器:** Docker + Docker Compose
- **部署:** Kubernetes (可选)
- **CI/CD:** GitHub Actions

## 4. API 接口文档

### 4.1 公司管理

#### GET /api/v1/companies/
获取公司列表

**参数:**
- `skip` (int): 跳过记录数
- `limit` (int): 返回上限
- `technology_type` (string): 技术路线筛选
- `country` (string): 国家筛选

**响应:**
```json
[
  {
    "id": 1,
    "name": "Commonwealth Fusion Systems",
    "country": "United States",
    "founded_year": 2018,
    "technology_type": "Tokamak",
    "website": "https://cfs.energy",
    "description": "...",
    "created_at": "2026-03-06T10:00:00"
  }
]
```

#### GET /api/v1/companies/{id}
获取公司详情

#### POST /api/v1/companies/
创建新公司

#### PUT /api/v1/companies/{id}
更新公司信息

#### DELETE /api/v1/companies/{id}
删除公司

#### GET /api/v1/companies/{id}/funding
获取公司融资历史

### 4.2 融资数据

#### GET /api/v1/funding/
获取融资轮次列表

**参数:**
- `skip`, `limit`: 分页
- `company_id`: 公司筛选
- `round_type`: 轮次筛选
- `year`: 年份筛选

#### GET /api/v1/funding/stats
获取融资统计

**响应:**
```json
{
  "total_funding": 5000000000,
  "total_rounds": 50,
  "avg_round_size": 100000000,
  "median_round_size": 80000000,
  "largest_round": 1800000000
}
```

#### GET /api/v1/funding/stats/by-technology
按技术路线统计

#### GET /api/v1/funding/stats/by-country
按国家统计

#### GET /api/v1/funding/stats/timeline
融资时间线

### 4.3 报告系统

#### GET /api/v1/reports/
获取报告列表

#### POST /api/v1/reports/generate/industry-overview
生成年度行业概览

#### POST /api/v1/reports/generate/company-analysis/{id}
生成公司分析报告

#### POST /api/v1/reports/generate/quarterly-report
生成季度报告

使用 ECharts 世界地图展示公司地理分布，颜色深度表示公司数量。

## 6. 报告生成系统

### 6.1 报告类型

| 类型 | 说明 | 价格 |
|------|------|------|
| annual_overview | 年度行业概览 | 免费 |
| quarterly | 季度报告 | ¥199 |
| company_analysis | 公司深度分析 | ¥99 |

### 6.2 生成流程

```
1. 接收生成请求
   ↓
2. 查询数据库获取相关数据
   ↓
3. 计算统计指标
   ↓
4. 生成 JSON 报告内容
   ↓
5. 保存到文件系统
   ↓
6. 创建数据库记录
   ↓
7. 返回报告 ID 和内容
```

```json
  "key_findings": [...],
  "data": { ... },
  "charts": [...],
  "recommendations": [...]
}
```

## 7. 部署指南

### 7.1 开发环境

```bash
# 克隆项目
git clone https://github.com/FusionAI-Lab/FusionAI-Lab.git
cd FusionAI-Lab

# 启动所有服务
docker-compose up -d

# 初始化数据库
docker-compose exec backend python scripts/seed_data.py

# 访问
# 前端：http://localhost:3000
# API: http://localhost:8000
# Swagger: http://localhost:8000/docs
```

### 7.2 生产环境

使用 Kubernetes 部署：

```bash
# 创建命名空间
kubectl create namespace fusion-lab

# 应用配置
kubectl apply -f k8s/

# 检查状态
kubectl get pods -n fusion-lab
```

### 7.3 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| DATABASE_URL | PostgreSQL 连接串 | - |
| REDIS_URL | Redis 连接串 | redis://localhost:6379 |
| SECRET_KEY | JWT 密钥 | - |
| CORS_ORIGINS | 允许的源 | http://localhost:3000 |
